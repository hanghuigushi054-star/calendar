# 就活逆算スケジュールアシスタント (Job Hunting Reverse Schedule Assistant)

## 概要 (Overview)
就職活動やインターンシップの選考管理をサポートするWebアプリケーションです。
企業からの案内メールやマイページの募集要項のテキスト、またはスクリーンショット画像を読み込むことで、AI(Gemini)が最終締切を特定し、「いつまでに何をすべきか」というアクションプランを目標日から逆算して自動生成します。

## 主な機能 (Features)

* **スケジュール自動生成 (テキスト・画像対応)**
  * 企業からのメールテキストや募集要項の画像をアップロードするだけで、AIが自動で「最終締切日」などの重要情報を読み取ります。
  * 自分が設定した「前倒し目標日」を基準に、ES提出、Webテスト受検、面接対策などの具体的なスケジュールを逆算して提案します。
* **卒業年度に基づいた予測**
  * 自身の卒業年度（◯◯年卒）を初期設定することで、AIが日程を推論する際の精度が向上します。
* **カレンダー履歴・タスク管理**
  * 解析したスケジュールをカレンダーに保存し、日々のタスクとしてカレンダー形式で確認できます。
  * 完了したタスクにはチェック（OKマーク）をつけて、進捗を管理することができます。
  * タスクの日付を後からずらせる機能（リスケジュール機能）を追加しました。
* **企業の選考状況・マイページ情報・選考メモの一元管理**
  * 「自己PR」「ガクチカ」「長所・短所」「志望動機」など、エントリーシート作成時に頻繁に使用する情報をアプリ内に保存できます。
  * 選考スケジュールと合わせて、必要な情報をすぐに引き出せるようになります。
  * 選考ステータス、マイページのログインID/パスワードの一元管理機能、説明会やES、Webテストの感想を保存できる選考メモ機能について記載しました。


## 技術スタック (Tech Stack)
* **Frontend:** React, TypeScript, Tailwind CSS, Vite
* **Icons:** Lucide React
* **AI Integration:** Google Gemini API (`@google/genai`)
* **Date Manipulation:** date-fns

## 使い方 (How to use)
1. **初期設定:** 初回アクセス時に、自身の「就活の卒業年」を選択して開始します。
2. **解析・登録 (Input Tab):** 
   * スケジュールを終わらせたい「前倒し目標日」を入力します。
   * 企業の募集要項のテキストを貼り付けるか、スクリーンショット画像をアップロードします。
   * 「スケジュールを逆算する」ボタンを押すとAIがプランニングを行います。
   * 結果を確認し、「カレンダーに保存」を押してデータを蓄積します。
3. **カレンダー履歴 (Calendar Tab):**
   * カレンダー上でタスクのある日を確認・クリックして詳細なタスクを確認します。
   * 完了したタスクのチェックボックスをクリックして、進捗を管理します。
   * パスワード等の登録や選考メモへのアクセス、日付入力欄からのリスケジュール方法について追記しました。
文章を少しだけ整え、見やすく改善しています。
4. **ES・プロフィール (Profile Tab):**
   * 選考に必要な自己PRやガクチカなどの文章を作成・保存して備忘録として活用します。
